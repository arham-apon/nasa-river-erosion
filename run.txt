TROUBLESHOOTING
---------------
- "py is not recognized": use "python" instead of "py -3.14" (check "python --version" says 3.14).
- pip install fails on one package: make sure it is Python 3.14 (the lock file is for 3.14).
- Dashboard page is blank: open it through http://localhost:8000/dashboard.html, not by
  double-clicking the file; and keep the server window open.
- Port 8000 busy: use another number, e.g. "python -m http.server 8010 --directory data\web"
  and open http://localhost:8010/dashboard.html.
- Full details: docs\REPRODUCE.md and docs\step_*.md
